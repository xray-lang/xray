# 共享文法

`language.ebnf` 是文法产生式的唯一可编辑定义。`views.json` 为参考章节和附录选择具名产生式，不保存右侧副本。生成器拒绝重复定义、未知引用及无人使用的产生式。

本次收敛覆盖原有 61 处双语文法展示。相同产生式的紧凑形式以原附录 A 为整理起点，同时保留正文已接受的目标形式。具体消歧如下：

- 匹配的 `BindingPattern` 与声明解构的 `DeclarationPattern` 分开命名，避免一个名称承载两套定义。
- `ForInPairStmt` 表达两个循环绑定；`ForInTupleStmt` 表达单个元组解构绑定。`ref` 形式保留为已接受目标，不声称当前已实现。
- `ForInit` 使用变量声明或表达式；循环分隔分号由 `ForStmt` 定义，避免通过 `ExprStmt` 重复要求分号。
- 统一标识符、数字、表达式和类型参数产生式的别名；补齐正文已经引用的 `StaticBlock`。
- 前导小数点浮点形式保留 §1.6 的既有目标；`GoOption` 保留任务 335 已接受的调度选项；参数类型保留任务 340 的 `escaping` 目标及其函数类型限制。

这些规则描述接受的语法，不从解析器当前能力反推目标。共享源门验证唯一性、引用和投影一致性；它不证明整个文法与手写解析器等价。解析器支持需要相应的正例、反例及执行测试。
