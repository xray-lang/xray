# tests/ci_exclusions.txt
# ----------------------------------------------------------------------------
# ctest lanes that CI skips, and the reason each one is skipped.
#
#   <test name>  LANE=<lanes>  ISSUE=<ref>  ADDED=YYYY-MM-DD  OWNER=<contact>
#                REASON=<prose to end of line>
#
# Comment lines and blank lines are ignored. One test per line; the fields may
# appear in any order after the name, and REASON must come last because it runs
# to the end of the line.
#
# Lanes:
#   core       the sanitizer and coverage jobs' `ctest --exclude-regex`
#   release09  the 0.9 consolidation gate the unit-tests job runs
#   gate       scripts/run_release_09_gate.py's own KNOWN_AOT_BOUNDARY_RE
# A test may name several, comma separated.
#
# Rules, enforced by scripts/check_ci_exclusions.py (ctest entry
# `ci_exclusion_discipline`, so it runs locally and in CI):
#   - ADDED must be <= 30 days old. This is the same window
#     tests/known_failures.txt uses, and for the same reason: an exclusion
#     nobody has re-justified in a month is not a decision, it is sediment.
#   - ISSUE must point at something a reader can follow.
#   - OWNER must be a reachable contact.
#   - REASON must say what the exclusion costs -- what this lane is the only
#     thing checking -- not merely that it is red.
#   - Restoring a lane means deleting its line. Do not comment it out.
#   - .github/workflows/ci.yml derives its regexes from this file. It must not
#     restate them; the gate fails if it does.
#
# WHY THIS FILE EXISTS
#
# Until 2026-08-28 twenty-one names lived as two inline regexes in
# ci.yml, whose own comment said "Adding a name is a decision to stop testing
# something, so it needs a reason recorded next to it" -- while not one of the
# twenty-one carried a reason, a date, or an owner. The only prose beside them
# described four names that had already been removed.
#
# The archaeology behind this file, done before writing it:
#
#   - Twenty of the twenty-one entered on 2026-07-17 in three commits
#     (ff452f607, c542fe38f, bd8b3611c) whose message bodies are empty. Not
#     "the reason is recorded elsewhere" -- no reason was written.
#   - The rule demanding a reason (ci.yml:18-19) was added on 2026-07-30 by
#     fc0e244b2, thirteen days later, and was never applied retroactively.
#   - The one entry that did have a reason, test_vm_exception, has had it
#     revoked by events: d38bacfa0 (2026-04-26) excluded it on Linux only,
#     writing "macOS ARM64 retains a full ctest run with no exclusions", and
#     7306b4b01 (2026-07-17, empty body) deleted that guard and excluded it on
#     macOS too. The explanatory comment went with it.
#
# And the exclusions demonstrably hid regressions:
#
#   - c0707a8a9 (2026-08-05): parallel.map/mapInto/reduce refused native builds
#     when the optional Options argument was omitted. The commit says the
#     symptom "is what stdlib_embedded_layout had been red on" -- for nineteen
#     days, inside an excluded lane.
#   - e0db27358 (2026-08-05): every enum declared through `xray eval` /
#     xray_vm_dostring() / `xray run -` got zero variants. "test_vm_api,
#     test_vm_exception and test_vm_parallel_isolate were all red on this one
#     cause" -- meaning test_vm_exception had not been red for the SEGFAULT
#     its 2026-04-26 exclusion cited for months, and nobody was told.
#   - 14ac2ca1f (2026-08-05): `x as T` on an already-T value lost move/alias
#     provenance; the symptom is exactly the diagnostic sys_thread_vm asserts.
#   - 02cc78c07 (2026-07-30): "the other two are missing or wrong test assets
#     that were failing their own gates" -- aot_freestanding_provider_abi and
#     byte_array_aot_c90_hotpath, both excluded, both red.
#   - c6dbbd257 (2026-07-20): "The coro-heap UAF that previously crashed this
#     test is fixed" -- http_static_route_full_parse's actual cause was fixed
#     three days after it was excluded. It stayed excluded for another 39.
#
# So every ADDED date below is 2026-08-28: this is the first time any of these
# has been justified in writing, and the clock starts now. Several of them are
# expected to leave this file as soon as somebody measures them -- the
# archaeology found no evidence that most are still failing, only that nobody
# has looked. `ctest -R '^<name>$'` is the whole experiment.
#
# The template for leaving is already in the history. When aot_filetests and
# the differential lanes came back (20daf3da3, bb02ac7f9, fc0e244b2), each
# removal recorded four things: the date, what that lane was the only driver
# for, what replaced the blanket exclusion (a shrink-only ratchet), and the
# cost of the exclusion in numbers -- "PR CI ran zero VM/AOT comparisons on a
# two-backend language". Write those four things when you delete a line here.
#
# WHAT THE FIRST MEASUREMENT REMOVED, same day
#
# Writing the reasons down was half of it; running the twenty-one was the other
# half, and it had never been done. `ctest -j2` over all of them, Release, no
# sanitizer, XRAY_STDLIB_VM_FASTPATHS=OFF: 7 passed, 13 failed, 1 timed out and
# then passed in 24.4s when re-run serially (query_surface_residue, whose 30s
# TIMEOUT was raised in the same change -- 18.7s on an idle machine is not a
# budget, it is a coin flip).
#
# Six lanes were deleted from this file on the strength of that, restoring
# their blocking coverage:
#
#     stdlib_migration_contracts        stdlib_self_hosting_consistency
#     binary_stdlib_surface_inventory   binary_public_native_readiness
#     string_surface_residue            query_surface_residue
#
# All six are pure Python gates: their `add_test` COMMAND takes no
# $<TARGET_FILE:xray> and reads only source and metadata, so their verdict
# cannot depend on the build configuration, and passing here means passing in
# every CI job. Deleting them is not a guess.
#
# Two more pass here and are kept anyway, with the experiment that would remove
# them written on their line: test_vm_exception and
# aot_freestanding_provider_abi both consume the compiler binary, so a Release
# pass says nothing certain about the Debug and sanitizer builds CI uses.
#
# The remaining thirteen were measured failing, and each line now says so with
# its wall time. That converts "excluded, reason unknown" into "excluded,
# failing, here is what it costs" -- which is a debt, not a mystery.
# ----------------------------------------------------------------------------
