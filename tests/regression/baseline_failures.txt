# ----------------------------------------------------------------------------
# Ratchet baseline for the tests/regression corpus.
#
# WHY THIS FILE EXISTS
#
# scripts/run_regression_tests.py has zero CMakeLists references and no ctest
# entry: 457 regression cases had no gate at all, and 48 of them had rotted
# unnoticed. Wiring the corpus straight in as a hard gate would have made every
# tier red on arrival and taught everyone to ignore it.
#
# So the corpus is gated from today forward: scripts/t.py fails on any failure
# NOT listed here, and also fails when a listed case starts passing without
# being removed. The list can only shrink.
#
# PROVENANCE: re-captured 2026-08-19 against
# rewrite/vm-aot-unified-target-machine. The 2026-07-31 capture was taken before
# the unified-target-machine migration and had stopped describing this tree: of
# its 36 lines, 28 had started passing, while 74 real failures were not listed
# at all. A ratchet that neither catches new breakage nor reports its own fixes
# gates nothing, so the list is re-pinned to measured truth.
#
# WHAT THESE 73 ARE: not a backlog of regressions but the work of tasks 269-283
# seen from the test corpus. 47 of them fail inside the semantic plan, before
# either backend runs, because the plan layer is fail-closed and does not yet
# state every construct the corpus uses. The remaining 26 fail earlier or later
# -- at parse, in the analyzer, or at run time -- and are ordinary defects.
# By diagnostic:
#
#     27  XR_SEM_0019   aggregate field identity / grounded call authority
#     26  (other)       parse, runtime and analyzer failures
#      7  XR_SEM_0018   capture with no storage domain (see known_bugs: the
#                       analyzer publishes one only for escape, transfer and
#                       const-shared, so an ordinary local arrives unknown)
#      6  XR_OWN_3002   null in a nullable reference; the model asks whether a
#                       value's TYPE is an ownership root (see known_bugs)
#      3  XR_OWN_3001   ownership balance goes negative (see known_bugs)
#      1  XR_SEM_0009   `t is (int, string)` -- a tuple type test reifies an
#                       XrClass pointer into a constant, which is VM-only
#      4  XR_SEM_0016 / XR_OWN_3003 / XR_OWN_3005
#
# So this file doubles as the 269-283 coverage worklist: each construct the plan
# layer learns to state should delete lines from here, and the list only shrinks.
#
# One test path per line. Comments and blanks ignored.
