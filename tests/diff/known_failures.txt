# Backend-differential ratchet baseline
#
# Every line is a VM/AOT divergence that fails today and is tracked, not
# forgotten. The net still gates all 471 other cases.
#
# Rules
#   - The list may only shrink. run_backend_diff_fast.py fails the run when a
#     case outside this list fails AND when a listed case starts passing, so a
#     fix must delete its line in the same change.
#   - Adding a line requires a written reason under one of the groups below.
#   - Never add a line to make an unrelated change go green. A VM/AOT divergence
#     means one of the two backends is wrong about the language.
#
# Established 2026-07-31, when the differential net was moved out of the CI
# exclusion list. It had been excluded wholesale because a minority of cases
# were red — which left the other 471 ungated as well. The net compares the same
# .xr through both backends byte for byte and is the only thing that can catch
# "VM and AOT disagree"; running none of it was strictly worse than running it
# with a written list of exceptions.
#
# One case path per line. Comments and blank lines ignored.

# --- Group 1: xr_aot_scope_exit arity ---------------------------------------
# Cleared 2026-07-31. The emitter had been updated to call
# xr_aot_scope_exit(ctx, mode) while the helper still declared a third
# out_value parameter, so the AOT build failed outright. A scope block is a
# statement and produces no value, and the value the scope settles on already
# rides in XrAotResult.value — the out-parameter was a second output channel
# for the same value that no caller ever read, so the declaration followed the
# emitter rather than the other way round. The seventh case filed here,
# sys_process_direct.xr, was never a scope_exit failure at all; it is a missing
# stdlib member and has moved to Group 2.

# --- Group 2: native struct members missing from the language surface --------
# The program reads members the type does not declare: DateTime.year/month/
# timestamp, CookieJar.count, Process.id.
#
# datetime_* and http_cookie_* fail only under AOT — the emitted C omits fields
# the VM resolves through its own object model, which is exactly the class of
# divergence this net exists to surface.
#
# sys_process_direct.xr is different and must not be read as the same bug: both
# backends reject it identically with "type 'Process' has no member 'id'", so
# the member is absent from the analyzer's surface, not just from the emitted
# C. It is filed here because the missing member is the shared root cause.
tests/diff/cases/semantics/stdlib/datetime_core_direct.xr
tests/diff/cases/semantics/stdlib/datetime_int_arg_shared_core.xr
tests/diff/cases/semantics/stdlib/http_cookie_pure_direct.xr
tests/diff/cases/semantics/stdlib/sys_process_direct.xr

# --- Group 3: union overlay literals -----------------------------------------
# "literal for type 'U32Bytes' is missing field 'b'" — a union literal is
# rejected for not initialising every member, but a union's whole purpose is
# that exactly one member is live. Both backends fail here (vm=1, aot=200), so
# this is a front-end rule that contradicts the feature, not a backend gap.
tests/diff/cases/semantics/oop/union_fixed_array_overlay.xr
tests/diff/cases/semantics/oop/union_fixed_layout_overlay.xr
