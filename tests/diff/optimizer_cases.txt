# Cases that must run through the Xi middle end to mean anything.
#
# What -O actually selects. The Xi optimization level is session policy, not
# the host optimization flag: the built-in policy gives both VM and native
# compilation the same XI_OPT_LIGHT pre-plan pass set. The -O flag reaches only
# the host C compiler and the link manifest. Use --xi-opt explicitly when a
# case must exercise a deeper Xi pass set.
#
# Consequently, XRAY_AOT_TEST_OPT=2 still changes only the host compiler's flag.
# This manifest names programs whose answers depend on the middle end; a lane
# that intends to exercise deeper Xi passes must also provide XRAY_XI_OPT.
# backend_diff_optimized sets both executors to full explicitly.
#
# A VM-only full-policy lane remains useful when the native backend rejects a
# program before reaching the middle-end behavior under test.
