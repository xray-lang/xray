# Cases the differential net cannot compare
#
# A line here is a case a backend refuses to build at all, so the run produced
# no verdict about whether the two backends agree. That is a coverage limit,
# not a divergence: known_failures.txt beside this file is for cases where both
# backends ran and disagreed, and mixing the two is what made this net
# unreadable -- hundreds of unfinished target authorities buried the one real
# disagreement it had found.
#
# Established 2026-08-16 during the unified target-machine work, when the AOT
# backend went fail-closed ahead of its per-construct authorities. Every entry
# is expected to leave as its construct gains one. The count here is the honest
# measure of how far that migration has to go.
#
# Rules, the same ratchet as known_failures.txt
#   - The list may only shrink. A case outside this list that stops building is
#     a backend regression and fails the run; a listed case that starts building
#     must have its line deleted in the same change.
#   - Do not add a line to make a change go green. Adding one says a case that
#     used to be comparable no longer is, which is a regression by definition.
#
# One case path per line. `#` starts a comment, blank lines are ignored.
#
# --- the inline comment on every line ---------------------------------------
#
# Each line carries the first refusal that case actually hit, with the
# case-specific operands (hashes, value ids, opcodes, absolute paths) stripped
# so that two cases blocked on one gap read alike. It is measurement, not
# policy: it says where the case stops today so the next reader does not have
# to rebuild the tree to find out. It carries no promise that the refusal is
# correct -- deleting the line when the case builds is still the only thing
# this file asserts.
#
# `vm too:` prefixes a case the VM also refuses at compile time. Those are not
# AOT coverage gaps at all: the case currently runs on neither side, and
# chasing a target authority for it is chasing the wrong layer.
#
# Measured 2026-08-28 on 00f665c5c (tree afe293b71) with:
#   cmake -S . -B build-nofp -G Ninja -DCMAKE_BUILD_TYPE=Release \
#         -DXRAY_STDLIB_VM_FASTPATHS=OFF
# FASTPATHS=OFF is not a detail: the default configuration does not finish
# building on this base, so every annotation here is an OFF-configuration
