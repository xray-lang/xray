# Cases the embedded-bytecode lane cannot compare
#
# A line here is a case the default `xray build` refuses to produce a binary
# for, so the run compared nothing and reached no verdict about whether the
# serialize/deserialize round trip preserves the program. That is a coverage
# limit, not a divergence; known_failures_embedded.txt beside this file is for
# cases where both forms ran and their output disagreed.
#
# Rules, the same ratchet as every other baseline here
#   - The list may only shrink. A case outside it that stops building fails the
#     run; a listed case that starts building must have its line deleted.
#   - Do not add a line to make a change go green.
#
# Established 2026-08-16, when build refusals stopped being counted as
# divergences. Before that this lane reported 77 failures with an empty
# baseline and was permanently red, which hid the nine real disagreements it
# had actually found.
#
# One case path per line. `#` starts a comment, blank lines are ignored.
#
# --- the inline comment on every line ---------------------------------------
#
# Each line carries the first refusal that case actually hit, with the
# case-specific operands stripped so that two cases blocked on one gap read
# alike. `vm too:` prefixes a case the VM also refuses at compile time -- for
# this lane that is the common case, because `embed` shares the VM's front end
# and only the bundling step past it is its own.
#
# Measured 2026-08-28 on 00f665c5c (tree afe293b71) with:
#   cmake -S . -B build-nofp -G Ninja -DCMAKE_BUILD_TYPE=Release \
#         -DXRAY_STDLIB_VM_FASTPATHS=OFF
#
# --- what the 48 refusals are blocked on ------------------------------
#
# 9 distinct first refusals; 44 of the cases are refused by the VM too.
#
#     20  coroutine lowering failed closed before publishing CoroLowered (at ownership)
#     13  XR_SEM_0019 coroutine state count disagrees with grounded call authority (at semantic-plan)
#      4  bytecode bundling failed
#      3  XR_OWN_3002 owner equivalence class has no ownership-defining operation (at semantic-plan)
#      8  (spread over 5 further first refusals, one or two cases each)
#
# `bytecode bundling failed` is this lane's own boundary and nothing else's:
# the front end published a program and the bundler would not serialize it.
